# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SevenShield.Core, please report it
responsibly by emailing:

**t.drescher@sevenshield.de**

Please do not open a public GitHub issue for security-related findings.

When reporting, please include as much of the following as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- The affected version/commit
- Any suggested fix, if you have one

## Response Time

This is currently a small, part-time-maintained project. I will do my best to
acknowledge reports within a few days and will keep you informed as I
investigate and address the issue.

## Scope

This policy covers `SevenShield.Core`, the cryptographic engine (AES-256-GCM
encryption, Argon2id key derivation, vault container format). The closed-source
`SevenShield.App` UI is not part of this repository and is out of scope here.

## Disclosure

Please allow time for a fix to be developed and released before publicly
disclosing any vulnerability. Coordinated disclosure helps protect users.

Thank you for helping keep SevenShield and its users safe.
